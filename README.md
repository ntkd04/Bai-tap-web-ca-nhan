# Portfolio - Nguyễn Trần Khánh Duy

Trang portfolio cá nhân giới thiệu bản thân, kỹ năng và các dự án thực tế.

## 🔗 Liên kết

- **Website:** https://vercel.com/ntkd04/bai-tap-web-ca-nhan/DS6TEVMTh8nZoheAoDHPANJcaNLL
- **GitHub:** https://github.com/ntkd04/Bai-tap-web-ca-nhan

## 🛠️ Công nghệ sử dụng

- HTML5 ngữ nghĩa
- CSS thuần: Flexbox, Grid, biến CSS, mobile-first
- JavaScript: ES Modules, DOM, event delegation, localStorage

## ✨ Tính năng

- Render 5 dự án từ `data.js` bằng template
- Lọc dự án theo tag + tìm kiếm theo tên
- Dark mode lưu vào `localStorage`
- Form liên hệ có validation
